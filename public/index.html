Project Roadmap

The 6-phase journey of the internship project.

0

Environment Setup

Docker Compose initialization and Mock Data generation.

1

Data Profiling

Identifying the "Hot Partition" bottleneck using PySpark EDA.

2

ScyllaDB Redesign

Applying Time-Bucketing Composite Primary Keys and TWCS.

3

PySpark ETL

Migrating data in parallel and archiving cold records to Parquet.

4

NLP Analysis

Sentiment classification and WordCloud generation for text data.

5

API & Dashboard

Serving data via FastAPI with Backtracking Pagination.

How to Deploy Locally

Run the entire pipeline on your own machine with a single script.

1
Clone & Install Requirements git clone https://github.com/BrooksNguyen/intern-vnpt-ai.git
2
Start Database Clusters docker compose up -d
3
Run the 1-Click Pipeline bash run_pipeline.sh This generates mock data, initializes ScyllaDB, runs PySpark ETL, and executes NLP analysis automatically.
